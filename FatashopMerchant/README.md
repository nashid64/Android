# Fatashop Merchant

The merchant (vendor) companion app for [Fatashop](../Fatashop), a single-vendor e-commerce platform. Built natively with Kotlin and powered by Firebase.

> The customer-facing shopping app is maintained as a separate project: [Fatashop](../Fatashop).

## Overview

Fatashop Merchant is used by the store owner to manage the shop that customers browse and buy from in the Fatashop app. Both apps share the same Firebase backend.

## Features

- Merchant authentication with Firebase Authentication
- Product management for the single-vendor store
- Input validation on forms
